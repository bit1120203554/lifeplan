## 目录用途

| 路径 | 内容与归档规则 |
|---|---|
| `internship/` | 实习和校招、工业简历、岗位调研、面试准备、HR／内推联系与投递记录 |
| `phd-apply/` | 申博、学术简历、导师联系、招生与学位／毕业安排；templates 放空白模板 |
| `algorithm-competition/` | 程序设计竞赛的历史准备与记录；当前求职面试训练以 internship 的提纲为入口 |
| `docs/` | 原始背景、跨任务周计划与分类索引；不堆放具体岗位或导师材料 |
| `legacy/` | 本地历史归档，镜像原仓库相对路径；Git 忽略，需另行备份 |
| `../projects/project4a/` 等 | 实际科研代码与实验仓库；LifePlan 保存执行计划和指向研究材料的引用 |
