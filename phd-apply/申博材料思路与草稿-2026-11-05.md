# 申博材料：在研项目怎样写，以及 Agent 研究计划草稿

2026-11-05｜供自己修改和裁剪；不覆盖现有简历、研究计划或 Word 中的未保存内容。

## 一、先确定材料的分工

你的材料可以讲一条连贯、但不必把所有经历强行说成同一方向的故事：

1. **ICCV 论文**证明你能够围绕真实问题完成建模、方法设计和实验，并把研究推进到发表。这是最扎实的成果。
2. **当前决策智能研究**展示你转向智能体以后关注什么问题、怎样分析旧方法的不足，以及为新思路做了哪些设计和原型检查。其研究效果还需要进一步验证。
3. **博士研究计划**说明你希望进一步研究智能体的什么能力、准备用什么方式检验，而不是承诺照搬当前两个方案或预告已经得到的结果。

这三部分共同支持申请，但不能互相替代：ICCV 一作不等于已经取得 Agent 方向的发表成果；新方向没有论文，也不等于相关探索不能作为研究经历。竞争力还取决于导师的方向、名额和申请池，无法从材料判断录取结果。

## 二、简历：先写清问题、做了什么、进展到了哪里

### 推荐排法

研究经历里保留 **IHRUT + 一项当前研究**。当前研究下面有两个方向：Id1 是主要篇幅，因为已有策略图、搜索与局间复盘原型，以及小规模运行；Id3 可作为一条独立子项，说明方案设计和历史数据分析。这样既能展示两条思路，也不会让两个尚处早期的方向看上去像两项已有成熟结果的研究。

如果版面允许、或面向博弈／决策方向导师，Id1 和 Id3 也可以分成两项。关键不是写成一项还是两项，而是让读者能看出每一项的实际阶段。月份应按本人实际开始的工作核定；把旧研究和后来形成的 Id1、Id3 写在同一连续时间段时，要表明它们属于逐步演变的研究工作。

### 方案 A：合并成一项，适合大多数首联简历

**大语言模型驱动的智能体决策与经验学习研究（在研）**｜2026 年—至今

- 面向稀疏反馈和多步决策任务，研究如何利用搜索与交互反馈，形成可检查、可复用的决策经验。
- 在长程规划方向，设计由状态特征、条件和可执行能力组成的策略图，探索结合有限搜索与反馈修订策略；围绕图执行、搜索和局间复盘开展原型运行与局部检查，涉及推箱子和地图导航任务。
- 在博弈决策方向，探索统计学习与大模型生成的策略程序如何协作，并基于历史搜索数据开展有限统计分析，为后续方案设计提供参考。

上述第三条的“有限统计分析”指旧数据上的探索性检查，不代表 Id3 的完整方法已经实现或产生对局收益。原型和分析使用 AI 辅助时，可如实描述本人实际提出、判断和推进的部分；不要把辅助完成的全部编码工作写成“独立完成”。

### 方案 B：拆成两项，适合需要展示具体研究思路时

**稀疏反馈长程规划中的智能体策略学习（在研）**｜2026 年—至今

- 研究有限搜索与环境反馈如何帮助智能体形成可检查、可复用的策略，以应对长程规划中的反馈稀疏问题。
- 设计由状态特征、条件和可执行能力组成的策略图；围绕图执行、有界搜索与局间复盘开展原型运行，并在推箱子和地图导航任务中进行局部检查。

**学习与推理协作的博弈决策智能体（方案设计与初步分析）**｜2026 年—至今

- 围绕棋类博弈中的策略形成，探索用统计学习筛选局面与行动相关线索，再结合大模型生成和检验可执行策略程序。
- 分析历史搜索数据及其反馈局限，为后续比较直接生成代码、统计筛选和策略学习等方案设计实验。

两个版本都使用“探索”“设计”“开展检查”等动作描述。选择时可按本人实际参与情况调整动词。若需要一句进展说明，可以写“目前处于原型与方法验证阶段”，不必在每条后面重复没有论文或没有性能提升。

### 已发表项目怎么支撑转向

**IHRUT：高光谱干涉成像复原**｜2024.09—2025.07

- 针对成像退化和训练数据缺乏的问题，建立物理退化模型与参数标定流程，构造仿真数据，并设计基于深度展开与 Transformer 的重建网络。
- 本人负责建模、标定、数据与网络设计、训练及实验；相关研究以第一作者发表于 ICCV 2025。论文信息可核对 [ICCV 官方页面](https://openaccess.thecvf.com/content/ICCV2025/html/Li_Physical_Degradation_Model-Guided_Interferometric_Hyperspectral_Reconstruction_with_Unfolding_Transformer_ICCV_2025_paper.html)。

这段着重展示能够迁移到新方向的科研能力：识别问题、建立模型、设计实验和完成论文。不需要把计算成像本身改写成 Agent 研究。

## 三、研究计划：以 Agent 为主线，保留问题的具体性

建议题目：**面向复杂任务的大语言模型智能体决策与持续改进研究**。

这里的 Agent 指能够观察环境、决定下一步行动、调用工具或执行动作，并根据反馈继续完成多步任务的系统。你的切入点不是泛泛地说“研究 Agent”，而是关注：**在反馈有限或不完整时，怎样判断发生了什么、决定下一步怎么做，并把有用经验应用到后续任务中。**

这个问题既能联系 Id1 的稀疏反馈与长程规划，也能联系 Id3 的搜索反馈、学习和可执行策略；其应用可以扩展到工具使用、软件任务或网页交互。现阶段无需承诺必须用策略图、必须无梯度，或者博士期间必须同时完成 Id1、Id2、Id3。也不能假设从准确模拟的推箱子环境迁移到网页等任务时，仍然可以免费重置或精确模拟。

现有 11 月 2 日研究计划在“如何开展首个可检验实验”上很具体，适合作为**技术备份**；对不同 Agent 导师首联或做通用申请时，可采用下面更宽一层的版本，再按导师方向调整一段。学校若有指定字数和格式，以实际要求为准。

### 研究计划草稿

**研究背景与目标。** 大语言模型为智能体理解任务、生成行动和使用外部工具提供了新的能力。在需要多步交互的任务中，智能体仍需根据有限反馈判断当前进展，并在错误、信息不足或环境变化时调整行为。我希望研究智能体如何利用交互和搜索得到的证据改进决策，并将有效经验应用到相似的新任务中，重点关注决策的可靠性、经验复用及所需计算与交互成本。

**研究问题一：如何利用不完整的反馈改进决策。** 一次行动没有带来预期结果，可能是策略不合适，也可能是观察不充分或后续步骤没有完成。例如，网页操作中按钮返回成功，并不能单独证明整个任务已完成。我希望研究智能体如何结合执行轨迹、环境返回和必要的检查操作，识别哪些判断有支持、哪些仍需要进一步确认，并据此选择继续执行、补充信息或调整计划。首先可在规则清楚、便于控制的规划任务中研究反馈质量和检查成本；后续再考察工具交互中无法精确模拟、检查也可能有代价的情况。

**研究问题二：如何把经验用于后续任务。** 我希望比较几种积累经验的方式，例如保留自然语言经验、组织可调用的技能或策略程序，以及结合参数学习筛选可能有用的线索。重点考察经验在什么条件下适用、错误经验是否会影响新任务，以及何时需要更新或放弃旧经验。我的现有规划和博弈研究提供了初步问题意识；具体采用哪种表示或学习方式，将根据实验结果和导师的研究方向调整。

**研究方法与验证。** 初期选择可控制的规划环境，固定模型、可用工具和任务划分，比较直接执行、利用已有反馈反思、使用历史经验，以及增加主动检查的方案。对于各方案，分别记录任务成功情况、未见任务表现、模型调用与 token、环境交互和检查成本；在相同或明确报告的总预算下比较，并分析经验是否真的改变决策。随后可选择一个工具使用或网页交互环境，检验相关思路在更复杂反馈条件下的适用性。若增加检查并未带来足够收益，或经验只对开发任务有效，则分析原因并调整研究问题，而不预设方法一定有效。

**已有基础与后续安排。** 我已完成一项以物理建模、数据构造和网络设计为核心的研究，并以第一作者发表于 ICCV 2025。转向决策智能后，我围绕稀疏反馈规划开展了策略图和搜索原型探索，也对博弈搜索数据及学习策略的可能方式进行了初步分析。博士阶段希望在上述基础上，结合导师团队在 **[此处填写具体方向或论文中真正相关的问题]** 的研究，进一步明确实验环境和可检验的问题。

### 相关工作怎么放

这些文献说明方向已有积累，也可帮助定位计划，而不是证明当前方案具有新颖性：

- [Reflexion，NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html)：将任务反馈整理成文字经验，供后续尝试使用。
- [Voyager，2023 论文](https://arxiv.org/abs/2305.16291)：在 Minecraft 中使用可执行技能库，研究智能体探索与技能复用。
- [WorldCoder，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/820c61a0cd419163ccbd2c33b268816e-Abstract-Conference.html)：通过交互构建程序表示的世界模型，并结合规划。
- [SkillLearnBench，2026 论文](https://arxiv.org/abs/2604.20087)：在其任务设置中比较从经验生成和改进技能的方法；可作为检查“经验在何处有用、何处失效”的近期参考。这里按公开论文核对，不据此声称已完成全面领域查新。
- [WebArena，2023 论文](https://arxiv.org/abs/2307.13854)：可复现的网站交互环境与任务，适合了解网页智能体的评测条件；是否采用取决于实际计算资源及研究问题。

写正式版本前，优先阅读拟联系导师的相关论文，再核对与上述工作的具体区别；不要写“首次将大模型、搜索、经验和程序结合”。这几篇足以支持初步定位，不能替代完整查新。

## 四、面谈时怎样讲清楚尚未出成果的研究

**一分钟版本：**

> 我之前完成的工作主要是计算成像，以第一作者发表了 ICCV 论文，过程中负责建模、标定、网络和实验。转向决策智能后，我开始关注智能体能否从有限的搜索和交互反馈中形成可复用经验。此前的方案在反馈质量和策略改进上遇到问题，也让我意识到需要区分“没有找到解”和“这个策略确实错误”。现在我围绕长程规划设计并运行了策略图相关原型，也在思考博弈场景中学习和可执行策略如何配合。这些研究还在早期验证阶段；博士期间我希望进一步研究 Agent 的可靠决策、经验积累与复用。

**如果被问到具体困难：**可以用旧实验中某个特征因实现问题没有正确触发，后来被当作无用部件删除的例子，说明为何不能把一次执行结果直接当成可靠的策略评价。这个观察支持重新研究证据与程序行为，但不能单凭它证明新方法有效。面谈前应以原始实验记录为准，自己确认能解释代码行为与证据范围。

**如果被问到个人贡献：**具体区分自己提出和调整的研究问题、作出的技术判断、实际参与的实验，以及借助 AI 辅助完成的资料与代码工作。只说自己能够解释、复现或指明记录的部分；这些研究工作并不需要包装成全部由本人逐行独立编写。

## 五、建议的下一步

1. 先选简历方案 A 或 B，把 Word 中未完成和不准确的项目内容处理好；确认日期与个人贡献，保留 ICCV 的清楚描述。
2. 研究计划先以第三节草稿为底稿，针对具体导师补一段真实的研究契合点；正式提交前再按院校模板增删，不必先完善所有实验。
3. 为面谈准备一个旧方案遇到困难的具体例子、一个 Id1 原型实际运行例子，以及一个博士阶段最想检验的问题。每个例子能讲清“做了什么、看到了什么、还不能说明什么”即可。

**证据与置信度：**对本地 Id1／Id3 所记录的阶段及上述已保存 Word 文字，判断依据为 11 月 5 日读取的文件，置信度较高；Word 中未保存的更改、本人逐项工作分工和精确起始月份需本人核对。对方案能否得到研究收益和导师是否感兴趣，目前无法判断。文献只核对了上述公开论文页面与摘要，并非完整查新。
