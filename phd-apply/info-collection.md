# 导师信息收集指南

## 信息收集清单

对每位目标导师，至少收集以下信息：

### 基本情况
- 职称（教授/副教授/AP）/ 博导资格
- 所在学院/实验室
- 近3年博士毕业去向
- 课题组规模

### 学术情况
- Google Scholar / DBLP
- 近3年发表的代表作（找3篇精读）
- 发论文的频率和期刊/会议档次
- 一作分配（学生一作多不多？）

### 口碑情况
- 知乎/小红书/水木搜索
- 询问在该校的同学/学长学姐
- 注意甄别：个别差评可能是学生自身问题，但多个类似评价要警惕

---

## 信息收集渠道汇总

| 渠道 | 用途 | 优先级 |
|------|------|--------|
| 导师个人主页 | 研究方向、论文列表、招生要求 | ⭐⭐⭐ |
| Google Scholar | 论文引用、影响力、合作关系 | ⭐⭐⭐ |
| DBLP | 完整论文列表、合著者网络 | ⭐⭐ |
| 知乎/小红书 | 口碑评价（需甄别） | ⭐⭐⭐ |
| 导师评价网 (pjlab.org) | 历史评价 | ⭐ |
| 直接联系在读学生 | 最真实的信息 | ⭐⭐⭐ |
| 学长学姐人脉 | 内部消息 | ⭐⭐⭐ |
| 学术会议/讲座 | 线下了解导师风格 | ⭐⭐⭐ |

---

## 防坑复查清单

联系每位导师前，自查：

- [ ] 知乎/小红书搜过"XX大学 XX"没有负面集中反馈
- [ ] 近3年组里学生论文没有出现"学生非一作"的异常模式
- [ ] 学生毕业时间正常（博士4-6年）
- [ ] 不是以横向项目为重的"项目组"风格
- [ ] 没有强制学生做与科研无关的事情的传闻
- [ ] 如果你有本校/熟人的渠道，问过那里的人
