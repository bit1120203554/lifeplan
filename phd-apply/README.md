## 核心策略
1. **毕业先落实**：确认已有成果使用条件、学位论文最小要求与实际送审日期。
2. **研究先收敛**：一条主线完成最小验证，不预先承诺同时三篇论文。
3. **申博现在开始**：已有 ICCV 和真实在研问题可以展示；每周约 1.5 小时，得到实质反馈后再增加投入。
4. **如实呈现跨方向经历**：说明已有研究能力、当前原型、失败与下一步；不用尚未证实的性能或理论结论包装。
5. **导师筛选**：核实任职、博导资格、当届名额及可验证口碑；北京研究实习作为能力与就业选择并行。
