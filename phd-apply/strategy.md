## 一、你的处境分析 (SWOT)

### 优势 (Strengths)
1. **已有A会论文 (ICCV 2025)** — 这在申博中是硬通货。即使是老方向，ICCV作为计算机视觉顶会，在CS申博中是有分量的，说明你有**完整做出一篇顶会论文的能力**
2. **双方向背景** — 计算成像/CV + 决策智能/算法博弈论。这在AI领域"交叉"趋势下可以是卖点
3. **本科履历扎实** — 奖项多、成绩好，说明基础学习能力没问题
4. **换导师经历（反过来说）** — 能说明你有判断力、在不良环境中仍产出了ICCV
5. **代码能力和科研能力是分开的** — 机试差≠科研能力差，这点要在简历和自我介绍中明确传达

### 劣势 (Weaknesses)
1. **新方向成果尚未投出** — 目前只有老方向论文，决策智能方向没有发表记录
2. **换导师导致的时间损失** — 半年空窗期，节奏被打乱
3. **无实习经历** — 虽然申博更看重科研，但也会被问到
4. **无牛推** — 新导师是硕导，学科影响力有限；老导师关系不好
5. **学校背景（相对劣势）** — 北理工CS在申请清北华五时不是优势

### 机会 (Opportunities)
1. **决策智能/博弈论 + 大模型时代** — 这个交叉领域目前非常活跃（LLM reasoning、multi-agent systems、mechanism design for AI）
2. **清北华五扩招趋势** — 很多学校AI方向在扩招博士
3. **你的经历独特性** — 跨方向且有顶会的申请人并不多
4. **普博 vs 直博** — 普博名额虽然少，但竞争者也更少（很多好学生直博了）

### 威胁 (Threats)
1. **时间紧张** — 已经6月底，很多导师名额可能已被占
2. **同校竞争** — 可能遇到清北本硕的申请者
3. **新论文如果难产** — 简历上缺一块
4. **导师口碑信息不对称** — 再次踩坑的风险

## 二、定位策略 — 怎么包装自己

### 核心叙事主线（建议）
> **"一个有CV顶会发表经验的决策智能研究者，关注如何将博弈论与学习方法结合"**

这条主线串起你两个方向：
- ICCV → 证明科研完整性和顶会发表能力
- 决策智能 → 当前和未来的研究方向
- 两者结合点 → 例如"多智能体系统中的感知-决策联合优化"、"基于博弈论的CV任务分析"

### 根据不同学校类型调整侧重点

| 学校/方向侧重 | 强调点 |
|---|---|
| 偏AI/ML的组 | ICCV发表经验 + 新论文中的方法创新 |
| 偏理论/博弈论的组 | 算法博弈论基础 + 数学功底 |
| 偏应用/交叉的组 | 两个方向的广度 + 快速学习能力 |

### 方向匹配建议

你目前的背景比较适合以下类型的导师：
- **算法博弈论 / 机制设计** — 与你当前方向直接对口
- **多智能体系统 (MAS)** — 结合博弈论和AI的热门方向
- **计算经济学 / 市场设计** — 理论方向，竞争相对小
- **决策智能 / 强化学习** — 与博弈论交叉密切
- **AI for Science / 计算成像交叉** — 能利用你的CV背景

## 三、联系导师策略

### 时间线
- **第一轮（6月下旬 - 7月中旬）**：联系"冲刺档"（清北华五），先发简历
- **第二轮（7月中旬 - 8月）**：联系"主申档"，根据第一轮反馈调整
- **第三轮（8月 - 9月）**：联系"保底档" + 跟进已联系导师
- **论文投出后**：立即更新所有已联系导师

### 邮件联系要点

**标题格式**: `2027届博士生申请咨询——[姓名]——[学校/方向]`

**正文结构**:
1. 自我介绍（背景、当前学校、专业、年级）
2. 研究方向与成果（用一两句话说清）
3. 为什么选该导师（读过他/她的哪篇论文，具体感兴趣）
4. 附简历和成绩单

**关键原则**:
- **每封邮件单独定制** — 必须提到导师的具体论文/工作
- **简洁** — 导师很忙，5-8句话为宜
- **附件PDF简历** — 不要用word
- **适当提及推荐人** — 如果有共同认识的人或学术联系
- **后续跟进** — 1-2周未回复，发一次简短的跟进邮件

### 同时联系多导师的注意事项
- 同一学校的不同导师可以联系，但要错开时间
- 如果A导师回复积极，告诉B导师时已决定跟A，坦诚即可
- 不要用"我已经联系了更好的组"这种施压话术

## 四、信息收集渠道

### 如何找导师
1. **清北华五CS/AI学院官网** → 师资页面 → 看年轻AP（助理教授）通常更缺学生
2. **CCF推荐会议/期刊** → 搜你感兴趣的关键词 → 看通讯作者的单位
3. **中国计算机学会 (CCF)** → 专委会名单（特别是AI、理论CS方向）
4. **学术论文数据库** → Google Scholar搜决策智能/博弈论相关论文
5. **知乎/小红书** → 搜"XX大学 博士 导师 评价"（注意辨别，有些是情绪输出）
6. **学长学姐/同学** → 人脉推荐是最靠谱的渠道

### 如何避坑（重点！）

鉴于你之前的经历，导师人品必须严格把关：

1. **三重验证法**：
   - 知乎/小红书/导师评价网 → 检索负面信息
   - 找该导师的**在读学生**或**已毕业学生**私聊（通过论文找联系方式，或通过学长学姐介绍）
   - 看该组的论文发表节奏 — 学生是否常年不能毕业？一作是导师还是学生？

2. **危险信号**：
   - 学生长时间无发表（博士4-5年无论文）
   - 知乎上有多个匿名负面评价
   - 课题组氛围"家族制"（导师掌控学生所有时间）
   - 导师近年论文都是通讯作者而非一作+通讯（可能抢学生一作）
   - 横向项目过多（学生被当劳动力）

3. **安全信号**：
   - 学生毕业去向好（去学术/工业界都有不错出路）
   - 论文发表稳定且学生挂一作
   - 课题组有清晰的学术传承
   - 回复你邮件时态度专业、尊重

### 推荐的资源
- **导师评价网 (pjlab.org)** — 但数据较旧
- **知乎搜索** — "XX大学 CS 博士 体验"
- **各大学BBS/论坛** — 如北大未名、水木社区
- **直接邮件问学生** — 找到目标组的学生，发邮件礼貌询问

## 五、关于你长期想法的评价

### "读博不是为了教职，而是去科技企业"
**完全合理，而且是越来越主流的路径。** 现在CS博士毕业去工业界是大趋势（北美AI方向博士去工业界的比例超过70%）。你的目标 — 培养科研能力、拿博士学位、走在技术前沿 — 其实和工业界研究岗（Research Scientist / Applied Scientist）非常契合。

### "想留在高校环境，喜欢校园生活"
博士期间好好享受校园生活没问题。但要清醒认识：博士毕业后去企业，和你在校园的感受完全不同。可以把这个动机当作"锦上添花"而非核心驱动力。

### 需要注意的一点
你的申博动机整体合理，但有一个潜在矛盾：**你读博是为了去企业 → 企业在乎的是你的research output和skill set → 你需要选一个能产出高质量论文的组**。所以择导师时，**学术产出 > 学校名气**。一个华五的大牛组可能比清北的普通组更适合你。

### "不尝试一定没有机会"
**完全正确。** 你现在的情况——有ICCV、有新方向进展——其实比很多申博的人强。普博申请者中，有顶会一作的并不多。你的不自信主要来自"竞赛不行"这一心结，但科研和竞赛是两回事。认真准备、积极联系，你有很大机会。
