## 基础知识：先走通一次机器学习过程

先把机器学习理解为：**用已有例子调整一条预测规则，再检查它在新例子上是否有用**。这一节使用很小的教学数据，先认识每个环节；真实研究还要处理噪声、数据划分和更复杂的模型。

### 基础 B-1｜样本、特征、标签、数据集

假设人为构造了三对数，希望学习从 x 预测 y：

| 样本编号 | 输入 x | 目标 y |
|---|---:|---:|
| 1 | 1 | 3 |
| 2 | 2 | 5 |
| 3 | 3 | 7 |

- **样本 sample**：一次观察，这里是一行。
- **特征 feature**：预测时提供的信息，这里只有 x；有多个特征时可以组成向量。
- **标签／目标 label／target**：希望模型预测的答案，这里是 y。
- **数据集 dataset**：许多样本组成的集合。
- **预测值**记为 $\hat y$，帽子表示“模型估计的”，与实际目标 y 区分。

在你的 ICCV 任务里，一个输入可以是一块有退化的成像数据，目标是一块对应复原数据；输入、目标都可以是多维数组。标签不限于一个类别编号。

### 基础 B-2｜回归、分类、无监督与强化学习

**回归**预测数值，如预测长度、温度或图像像素；**分类**预测类别，如一封邮件是否为垃圾邮件。二分类只有两类，多分类有多个类别。图像复原常按高维连续输出的预测问题处理。

**监督学习**使用输入和目标的配对例子。**无监督学习**没有同样形式的目标标签，例如按相似性分组。**强化学习**通过行动获得奖励，学习怎样决策，行动还可能影响之后会遇到的数据。

这些是任务与学习设定，不直接指定模型。神经网络、树模型等可以用于多种设定；“用了神经网络”和“用了强化学习”描述的层次不同。

### 基础 B-3｜模型、参数与超参数

**模型**是可调整的预测规则。先用直线模型：$\hat y=wx+b$，其中 w 控制斜率，b 控制整体平移。w、b 叫**参数**，由训练调整。

设 w=1、b=0，输入 x=2，预测为 2；设 w=2、b=1，预测为 5。这组参数也能正确预测上表另外两个例子，因为数据就是按这个规则构造的。

**超参数**控制怎样训练或限制模型，如学习率、树深、正则强度。常由人设置或根据验证数据选择。记住区别：训练通常调整 w、b；选学习率是在配置训练过程。

**基线 baseline**是用于比较的参照方案，可以是简单模型、已有方法或一个合理的规则。有新方法后，需要比较它比什么更好。

### 基础 B-4｜损失函数与训练：预测错了多少，怎样改

**损失函数**把预测与目标的差距表示为数值。对 x=2、y=5，若预测为 2，**残差**为 $\hat y-y=-3$，平方误差为 9；若预测为 4，平方误差为 1。

常见的**均方误差 MSE**是把每个样本的平方误差相加后取平均。**MAE**改为绝对误差的平均。使用哪种误差，决定了训练更重视哪些偏差。

一次基本训练过程是：

1. 取一批已有输入与目标。
2. 用当前参数计算预测。
3. 计算损失。
4. 求损失对参数的梯度，得到局部调整方向。
5. 优化器按学习率更新参数。
6. 重复，并在独立数据上检查效果。

**优化器 optimizer**负责具体更新规则。梯度与学习率的数值例子见基础 A-7；深度学习基础会把这个过程再算一遍。

### 基础 B-5｜训练集、验证集、测试集，以及泛化

**训练集**用于学习参数；**验证集**用于选择方案；**测试集**用于评价已经选定、冻结的方案。**泛化**指学到的规律能否用于未参与学习和选择的新例子。

可以用练习题、模拟题和正式考试理解：做练习时可以看答案改正，模拟题用来选择准备重点，正式考试才检查最终表现。反复根据同一套“正式考试题”改方案后，它实际承担了练习／开发作用。

**数据泄漏**是学习或选择时用了本应未知的信息。例如先在所有样本上计算标准化均值，再划分；或同一张图的近重复小块分别进入训练与测试。划分要依据独立对象，不能只看文件名不同。

**预处理**指模型前的数据整理，如缺失值填充、标准化、降维。需要从数据估计的预处理量通常只用训练数据拟合，再应用到其他部分。

### 基础 B-6｜欠拟合、过拟合、偏差与方差

**欠拟合**：模型或训练过程尚未抓住需要的规律，训练数据上就表现不足。比如用一个常数预测上表所有 y，无法同时拟合它们。

**过拟合**：模型适应了训练样本的特定细节或噪声，在新数据上表现变差。比如把每个训练输入和答案逐项记住，遇到稍有变化的输入便不会预测。

**偏差 bias**描述多次训练的平均预测与真实关系的系统性差异；**方差 variance**描述换一份训练数据后预测会变化多少。这里的方差与 A-9 同属“波动”概念，测量对象变成了模型预测。

排查时同时看训练与验证曲线：两边都差，要查数据、表达能力、优化；训练好而验证差，要查过拟合、划分和分布差异。曲线给线索，需要进一步验证原因。

### 基础 B-7｜正则、早停与标准化

**正则化 regularization**给学习加入限制或偏好，例如不鼓励权重过大。L2 正则常在数据损失外加上权重平方和的惩罚；L1 使用绝对值和，常有促稀疏作用。**正则强度 λ**控制这种限制的力度。

**早停 early stopping**根据验证表现选择训练停止点，避免持续训练只改善训练集。不能用最终测试表现反复选择停止点，又把它当完全独立的评价。

**标准化**常指减去训练集均值，再除以相应标准差，使特征尺度更可比。一个特征的数值量级很大时，可能影响距离、梯度与正则的作用；不是所有模型都同样需要标准化。

### 基础 B-8｜分类概率、阈值与交叉熵

一个二分类模型可输出“属于正类”的概率 p。**正类**是我们关注的一类，如垃圾邮件；并无“好”的含义，负类也无“坏”的含义。

**阈值 threshold**把概率转成决策，例如 p≥0.5 预测为正类。阈值可按错误代价调整：漏掉一条重要告警代价高时，可能希望提高召回，允许更多误报。

**逻辑回归 Logistic Regression**先算一个分数 $z=w^\top x+b$，再用 $\sigma(z)=1/(1+e^{-z})$ 把分数映射到 0—1。z=0 时 p=0.5，z 越大 p 越接近 1。

分类训练常用**交叉熵**：真实为正类时损失是 $-\log p$，真实为负类时是 $-\log(1-p)$。给真实类别的概率越低，惩罚越大。sigmoid 的作用是产生二分类概率，损失的作用是评价预测，两者分工不同。

### 基础 B-9｜先理解混淆矩阵，再看指标

对 100 个样本，假设得到下面结果：

| 实际情况 | 预测为正 | 预测为负 |
|---|---:|---:|
| 实际为正 | TP=18，正确找到 | FN=12，漏掉 |
| 实际为负 | FP=6，误报 | TN=64，正确排除 |

- **准确率 accuracy**：全部预测里正确多少，$(18+64)/100=0.82$。
- **精确率 precision**：报为正的结果里有多少是真的，$18/(18+6)=0.75$。
- **召回率 recall**：实际正类有多少被找到，$18/(18+12)=0.60$。
- **F1**：用调和平均综合 precision 和 recall，这里约 0.667；一项特别低会拖低它。

**类别不平衡**是各类样本数量差异大。若 100 个样本仅 1 个为正，全报负也有 99% 准确率，但正类一个都没找到。

**ROC／PR 曲线**通过改变阈值展示取舍。ROC 横轴是假阳性率，即实际负类被误报的比例，纵轴是真阳性率／召回率；PR 横轴是召回率，纵轴是 precision。**AUC**泛指曲线下的面积，ROC-AUC 与 PR-AUC 的对象不同。

**概率校准 calibration**关注数字概率是否可信：给一批样本预测接近 0.8，如果预测校准良好，这组里约 80% 应为正。类别预测正确、排序好、概率校准好，是不同层面的性质。

### 基础 B-10｜先认清常见模型在做什么

| 名称 | 第一层理解 | 进一步要留意 |
|---|---|---|
| 线性回归 | 多个特征按权重相加，预测数值 | 简单线性关系是否够用 |
| 逻辑回归 LR | 线性分数经 sigmoid 等映射，做分类 | 概率、阈值、特征表示 |
| 决策树 | 连续问“某特征是否超过阈值”，分到不同叶子 | 划分太细可能记住噪声 |
| Bagging | 训练多个重采样模型，再组合 | 模型之间是否过于相似 |
| 随机森林 RF | 一组有数据／特征随机性的树进行组合 | 树数、深度与相关性 |
| Boosting／GBDT | 按顺序加模型，修正当前组合的不足 | 学习率、树复杂度、噪声 |
| XGBoost | 带目标近似、正则与系统优化的树提升方法 | 先理解树提升，再补二阶细节 |
| SVM | 寻找有较大分类间隔的边界 | 核方法、尺度与计算成本 |
| kNN | 参考附近 k 个样本的答案 | 距离定义、尺度、高维问题 |
| k-means | 把样本分到 k 个中心附近 | 没有类别标签，簇不一定等于真实类别 |
| PCA | 用少数线性方向保留较多变化信息 | 高方差方向不一定最有预测价值 |

这里先记住任务与机制，不需要同时掌握所有算法推导。

### 基础 B-11｜指标、对照、消融与分布变化

**评价指标 metric**回答“怎样算做得好”，例如分类准确率、复原 PSNR、Agent 任务成功率。**训练损失**回答“优化时怎样给调整方向”。二者可以相关，但数值下降／上升不必完全同步。

**对照实验**比较不同方案；**消融实验 ablation**拿掉或替换一个组件，检查它贡献了什么；**配对比较**让两种方法面对相同样本、任务或随机设置，以减少无关差异。

比较时要关心**预算**：谁用了更多训练数据、计算时间或工具调用。增加资源后取得更高分，是一项现象；要进一步隔离机制本身的作用，需要合适对照。

**推理 inference**在机器学习语境下常指使用已有模型计算预测。新数据与训练数据的规律不同时，叫**分布变化／偏移**；例如训练都是清晰输入，使用时出现明显噪声。需要查输入、标签、预处理和任务条件，不能只看训练成绩。

## 20 道典型问答

### B01 [P0] 为什么划分训练、验证和测试？什么是数据泄漏？

训练集拟合参数，验证集选模型、阈值、超参数或 prompt，测试集评价已冻结方案。泄漏指训练／选择过程使用了预测时不可得的信息，或测试信息进入了这些过程。

例：先在全量数据拟合标准化／PCA，再划分；同一对象的近重复样本跨两侧；依据测试错误反复改 prompt。应先划分，预处理只在训练数据拟合，各侧复用转换；有对象／时间依赖就按相应单位划分。[官方示例](https://scikit-learn.org/stable/common_pitfalls.html)

### B02 [P0] 偏差与方差是什么？怎样从学习曲线判断问题？

偏差描述模型平均预测与目标的系统性差异，方差描述训练数据变化带来的预测变化。训练、验证都差可能欠拟合，也可能是数据／优化出错；训练好而验证差常见于过拟合、分布差异或泄漏造成的错觉。

平方误差下有偏差平方＋方差＋不可约噪声的经典分解，不能无条件套到所有损失。应同时检查数据、优化与学习曲线，不能凭“模型很大”就断言高方差。

### B03 [P0] Logistic Regression 为什么是分类模型？梯度是什么？

二分类令 $p=\sigma(w^\top x+b)$，优化 Bernoulli 负对数似然：$L=-y\log p-(1-y)\log(1-p)$。对 logit 的梯度为 p-y，对 w 为 $(p-y)x$。它输出类别概率，阈值将概率变为决策。

无额外特征映射时，决策边界对输入线性。用平方误差并非不能训练，但与这个概率模型的自然似然目标不同；实际实现用稳定的 logits 形式。推导联系 A11、A15。

### B04 [P0] L1 与 L2 正则有什么区别？

L1 对参数绝对值求和，具有促稀疏倾向，零点不可微可用次梯度等方法；L2 平滑地惩罚大权重，通常使参数收缩而不直接变为精确零。两者能约束复杂度，但不会保证测试性能提高。

特征缩放影响惩罚的相对意义；高度相关特征下 L1 的选择可能不稳定。普通 SGD 的 L2 与某种权重衰减写法可对应，自适应优化器下不能把所有 weight decay 都等同于加 L2，见 C03。

### B05 [P0] Precision、Recall、F1 怎么算？准确率为什么可能误导？

$$P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad F_1=\frac{2PR}{P+R}.$$

极不平衡时全预测多数类也可能准确率很高。Precision 关注预测正例有多可信，Recall 关注实际正例覆盖率；阈值改变二者及业务成本。分母为 0 时应明确约定；macro、micro、weighted 汇总也要说明，F1 不考虑 TN。[指标定义](https://scikit-learn.org/stable/modules/model_evaluation.html)

### B06 [P0] ROC-AUC 和 PR-AUC 有什么区别？AUC 高就可以上线吗？

ROC 描述 TPR 与 FPR，PR 描述 precision 与 recall；正例稀少且重点关注正例质量时，PR 曲线往往更贴近问题。ROC-AUC 可解释为随机正例分数排在随机负例前的概率，平分按约定处理。

AUC 不确定具体阈值、概率是否校准或错误代价，部署仍要看目标工作点。PR 曲线面积的不同积分约定与 Average Precision 不必相同。只改变类别先验且类条件分数分布不变时，ROC 可不变而 PR 会变。[官方解释](https://scikit-learn.org/stable/modules/model_evaluation.html#roc-metrics)

### B07 [P1] 预测 0.9 真就有 90% 概率正确吗？怎样做校准？

良好校准的二分类概率在“预测接近 0.9”的样本组内，应约有 90% 属于正类；不意味着每个单一样本都能被验证为 90%。可用可靠性图检查，使用独立验证数据拟合温度／sigmoid／isotonic 等校准方式。

Brier 与 log loss 是概率预测评分，受校准、区分能力等共同影响，降低它们不单独证明校准改善。ECE 依赖分箱等选择。联系 Agent：组合权重不自动等于客观正确率。[校准文档](https://scikit-learn.org/stable/modules/calibration.html)

### B08 [P1] 决策树怎样选划分？为什么会过拟合？

分类树常用信息增益或 Gini 降低，回归树可用平方误差降低。每步选对当前节点最有利的切分，不保证整体全局最优。树太深时可记住噪声，应限制深度、叶子样本数或剪枝。

连续特征不是每个样本值都无限搜索，通常考虑排序后的候选切分。树对单调特征缩放通常不敏感，但数据缺失、类别特征和模型实现仍需单独处理。

### B09 [P1] Bagging、Random Forest、Boosting 怎样区分？

Bagging 在重采样数据上训练多个学习器后组合，常用于降低方差；RF 还在节点划分时引入特征随机性，以降低树间相关。Boosting 按序添加模型，纠正当前组合的不足；梯度提升沿损失的负梯度拟合新学习器。

不能把“Bagging 降方差、Boosting 降偏差”当无条件定律。比较还要看树深、学习率、样本量、噪声和预算。[集成学习说明](https://scikit-learn.org/stable/modules/ensemble.html)

### B10 [P1] GBDT 为什么说是在拟合残差？XGBoost 的二阶信息有什么用？

平方误差下负梯度等于残差，因此这句话成立；一般可微损失下拟合的是负梯度，不一定是数值残差。XGBoost 使用目标的二阶近似并加入树复杂度正则，利用梯度和 Hessian 近似计算叶子权重及划分收益。

重点说明目标与更新，不必背整套系统优化。二阶方法不保证任意任务必胜，也不能只根据速度比较预测质量。[XGBoost 作者论文](https://arxiv.org/html/1603.02754v3)

### B11 [P1] SVM 的最大间隔与核方法是什么？

线性 SVM 在分类约束／损失和权重范数之间平衡，鼓励较大几何间隔；软间隔允许违例，常与 hinge loss 联系。核函数通过内积隐式表示特征映射，合法核需要相应半正定性质。

核 SVM 并非天然概率模型，若需要概率可额外校准；训练规模、核参数和特征标准化影响使用。先把线性形式讲清，再补对偶。

### B12 [P0] MSE、MAE、Huber 怎样选？

MSE 对大残差惩罚更强，在经典平方风险下最优预测对应条件均值；MAE 对异常值相对稳健，对应条件中位数；Huber 在小残差区二次、大残差区线性，平衡平滑与稳健性。

在独立高斯／Laplace 残差等模型下，MSE／MAE 分别可由负对数似然解释。选择取决于噪声和目标，不是“L1 永远更好”。ICCV 可追问：为何用 L1 训练却用 PSNR／SSIM 评价？回答代理目标与评价性质。

### B13 [P1] 为什么标准化？怎样避免预处理泄漏？

尺度差异影响距离、梯度条件数与正则强度，LR、SVM、kNN 等常受影响；树的阈值划分通常无须因为同样原因标准化。只在训练部分估计均值、方差、缺失填充值和降维参数，各验证／测试部分只 transform。

交叉验证中每折也必须这样做；用 Pipeline 封装预处理和模型有助于遵守该边界。[泄漏与 Pipeline](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)

### B14 [P1] kNN 的 k 有什么影响？为什么高维距离可能变差？

k 小更灵活且受噪声影响大，k 大更平滑但可能忽略局部结构；需要验证选择。朴素检索每个查询约 O(nd)，维度高时索引未必有效，距离可能集中且无关维度干扰邻近关系。

距离度量、归一化、样本密度和类别不平衡都重要；kNN 训练阶段少不等于整体计算便宜。

### B15 [P1] k-means 与 PCA 分别优化什么？

k-means 最小化样本到其簇中心的平方距离，交替分配与更新，受初始化和 k 影响，可停在局部解。PCA 对中心化数据寻找最大方差线性方向，等价于特定约束下最小化重建平方误差。

前者做聚类，后者做线性降维；最大方差不等于最有标签预测价值，低方差方向也可能携带判别信息。

### B16 [P1] 正例太少怎样处理？能先过采样再划分吗？

可考虑类别加权、训练集重采样、改阈值或补充数据；要以验证指标与错误成本选择。先划分，再仅对训练部分重采样，否则重复／合成近邻样本可能跨侧泄漏。

重采样改变训练先验，概率输出可能需要再校准。不能仅报告训练准确率，也要关注小类召回、precision 和不同切片。[数据边界](https://scikit-learn.org/stable/common_pitfalls.html)

### B17 [P1] 为什么不能对所有数据随机做 k-fold？

随机划分隐含相应独立性／交换性假设。同一用户、患者、原始图像或关卡的多个样本应按对象分组；预测未来要尊重时间顺序。分类可分层以保持比例，但分层本身不能消除分组依赖。

用同一验证反复选择模型会过拟合选择过程；可使用独立测试或嵌套交叉验证。划分要服务真实部署问题。[交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)

### B18 [P1] p<0.05 表示方法有 95% 概率有效吗？

不是。p 值是在指定零假设与统计模型下，得到当前或更极端统计量的概率，不是零假设为真的概率。还要报告效应大小、置信区间、实验单位，以及是否做了多次尝试／比较。

可配对时使用配对差值，别丢掉同任务比较的信息。线上 A/B 先定义随机化单位、主指标、观察窗口和分析规则；显著性不代替实际收益或随机化质量。[ASA 的解释原则](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)

### B19 [P1] 离线效果好，上线变差有哪些原因？

先查预处理、特征可用性、版本、训练／推理模式和评价实现。再查采样／用户／任务分布、标签延迟及分布变化：covariate shift 指输入分布变，label shift 指标签先验变，concept shift 指条件关系变，具体分析要写清假设。

补最新切片评测和漂移监测；重加权、再训练或再校准取决于问题。不能把全部失败都解释成“模型不够大”。

### B20 [P0] 如何证明一次提升来自提出的机制？

先冻结版本、数据划分与选择规则，比较合理强基线和必要消融；对齐模型、数据、搜索／调用／训练预算，记录额外成本。能配对就使用相同任务和随机设置，并报告失败类型与差值不确定性。

“多用十倍搜索后更高”不能单独支持机制有效。反复看过的测试关卡应如实标为开发比较；多 seed 测试不自动等于多个独立训练／编译。结合 A17、D10 回答自己的 ICCV 或 4a 例子。

## 三项练习

1. **指标手算**：TP=18、FP=6、FN=12、TN=64，计算 accuracy、precision、recall、F1；再解释阈值调整的代价。答案分别为 0.82、0.75、0.60、约 0.667。
2. **LR 手写**：用 NumPy 完成稳定 sigmoid／logits 损失、梯度更新和独立验证。检查单样本梯度、极端 logits、标签 shape；推导与数值有限差分可以互相核对。
3. **实验设计**：为 4a 最新版本写半页对照：估计什么收益、选哪个基线、固定哪些预算、哪些实例用于修改、哪些用于最终评价。这里练设计，不要求重跑大实验。

模型推导可查 [CS229 讲义](https://cs229.stanford.edu/main_notes.pdf)，实现边界优先查上面就近列出的官方文档。XGBoost 等模型只要求到与你岗位相关的深度，首轮不把全部搜推业务知识追加进来。
