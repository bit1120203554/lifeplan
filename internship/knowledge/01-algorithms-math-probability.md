## 基础知识：从概念和例子开始

这一节不假设你已经会推导。先理解一个词表示什么、能用来处理什么，再读符号。每次读一至两个小节即可；原来的面试题留作理解后的练习。

### 基础 A-1｜先看懂函数和常用符号

**变量**是用来表示一个数或对象的名字。**函数**是一条输入到输出的规则：$f(x)=2x+1$ 表示输入 x，输出它的两倍再加一；输入 3 得到 7。函数也可以接收多个数，输出一个数或一组数。

| 写法 | 含义 | 小例子 |
|---|---|---|
| $x_i$ | 一组数中的第 i 个；下标用来编号 | $x_1=2,x_2=4$ |
| $\sum_{i=1}^n x_i$ | 把第 1 到第 n 个数相加 | 2+4+6=12 |
| $\frac1n\sum_i x_i$ | 总和除以个数，即平均数 | 12/3=4 |
| $x^2$、$\sqrt x$ | 平方、平方根 | $3^2=9,\sqrt9=3$ |
| $\|x\|$ | 绝对值，即到 0 的距离 | $\|-3\|=3$ |
| $\exp(x)=e^x$ | 以常数 e 为底的指数函数 | $\exp(0)=1$ |
| $\log x$ | 本材料通常指自然对数；与 exp 互为逆运算 | $\log1=0,\log e=1$ |
| $\arg\min_w L(w)$ | 找使 L 最小的 w；返回的是 w | $L(w)=(w-3)^2$ 时返回 3 |

对数常用于把乘法变成加法：$\log(ab)=\log a+\log b$，要求 a、b 为正。后面概率连乘转成 log 相加，就是用这条性质。暂时不用背 e 的小数展开。

### 基础 A-2｜算法与数据结构分别是什么

**算法**是完成任务的明确步骤。比如“从一组数里找最大值”：先记住第一个数，再逐个比较，遇到更大的就替换，最后返回记录值。

**数据结构**是组织数据的方式，会影响哪些操作方便：

| 结构 | 怎样理解 | 常见用途 |
|---|---|---|
| 数组／列表 | 按位置排列的数据 | 按下标取值、顺序扫描 |
| 哈希表／字典 | 通过键找对应值 | 记录一个值是否出现、统计次数 |
| 链表 | 每个节点保存数据和下一个节点的连接 | 通过连接插入／删除；不能像数组那样直接跳到任意位置 |
| 栈 | 后进先出，如一叠盘子 | 括号匹配、记录尚未完成的调用 |
| 队列 | 先进先出，如排队 | 按发现顺序处理任务 |
| 堆 | 保证堆顶是当前最小或最大元素 | 反复取极值、维护前 k 大；堆不是完全排好序的数组 |

例：找“是否出现重复值”，可用字典边读边记录。要理解的不只是代码写法，还包括为什么查找已经出现的值方便。

### 基础 A-3｜复杂度与二分：输入变大时要多做多少工作

**时间复杂度**描述工作量随输入大小增长的趋势，**空间复杂度**描述所需存储的增长趋势。这里 n 表示元素个数，O 是“大 O”记号；它不直接代表具体秒数。

- 扫一遍 n 个数：O(n)。n 翻倍，主要比较次数约翻倍。
- 比较每一对数：O(n²)。n 从 100 到 1000，工作量可能约增加到 100 倍。
- 每次把候选范围减半：O(log n)。1000 个候选减到 1 个约需十次减半。

**二分查找**利用有序性排除半边。对 `[1,3,3,8,10]` 找第一个不小于 3 的位置：看中间的 3，答案可能更靠左；再检查左侧，最终得到下标 1。下标从 0 开始，因此它是第二个元素。

写代码时必须说明“当前哪些位置还可能是答案”，这叫**循环不变量**。它是每次循环开始时都成立的事实，用来解释算法为何不会丢掉答案。

### 基础 A-4｜图、树、路径，和 BFS／DFS

**图**由节点和边组成。节点可以表示城市、网页或游戏状态；边表示道路、链接或一次合法转移。**路径**是一串相连的边；有向边有方向，带权边还记录距离或代价。无向树是连通且没有环的图，选定根后可按父子关系组织。

例如 S 连到 A、B，A 连到 C：

```text
S → A → C
└→ B
```

**BFS（广度优先搜索）**先处理离 S 一步的 A、B，再处理两步的 C，常用队列。每条边代价相同，按层扩展就能找到最少步数路径。

**DFS（深度优先搜索）**沿一条路先走下去，走不通再返回，常用栈或递归。它能探索可达节点，但首次找到的路径不保证最短。图可能有环，因此要记录已访问节点，避免反复绕圈。

### 基础 A-5｜递归、回溯、动态规划与贪心

**递归**是函数调用自身处理更小的问题，必须有停止条件。计算树的节点数，可以把问题分成“当前节点＋各子树节点数”。

**回溯**是在多个候选之间试探：选一个、继续探索、返回时撤销选择，再试别的。例如枚举不同排列。

**动态规划（DP）**给可复用的子问题保存答案。求最少硬币数时，把“凑成金额 s 最少要几枚”记为 `dp[s]`，通过更小金额的答案推出它。写 DP 前先用一句话定义状态，不先猜转移公式。

**贪心**每步直接选当前看起来最好的。它需要正确性依据：硬币 1、3、4 凑 6，每次取最大得到 4+1+1，而 3+3 更好，所以这个规则在该币制下不成立。

### 基础 A-6｜标量、向量、矩阵与维度

**标量**是一个数；**向量**是一组有顺序的数；**矩阵**是按行列排列的数。可以把一位样本的多个特征写成向量，把多位样本放成矩阵。**维度／shape**说明每个轴上有多少元素。

例如两个样本、每个两个特征：

```text
X = [[1, 2],     X 的形状是 2×2：两行、两列
     [3, 4]]
w = [2, 1]      看成两个权重组成的列向量
Xw = [1×2+2×1, 3×2+4×1] = [4, 10]
```

**内积**是对应位置相乘再相加，例如 `[1,2]` 与 `[2,1]` 的内积为 4。矩阵乘法把每一行分别与权重做内积。**转置**把行列交换，记为 $X^\top$。

**范数**衡量向量大小。L2 范数是平方和的平方根，例如 `[3,4]` 的 L2 范数为 5；L1 范数是绝对值之和，为 7。后面看到 $\|w\|_2^2$，就是权重平方和。

### 基础 A-7｜导数、梯度与梯度下降

**导数**描述输入小幅变化时，输出怎样变化，可理解成曲线在当前位置的斜率。$L(w)=(w-3)^2$ 在 w=1 时为 4，导数 $L'(w)=2(w-3)$ 为 -4：此处增大 w 会让 L 减小。

**偏导数**是只改变一个变量、固定其他变量时的变化率。**梯度**把所有参数的偏导排成向量，用 $\nabla L$ 表示。

**梯度下降**按负梯度方向调整参数：$w_{new}=w-\eta L'(w)$。$\eta$ 叫学习率，控制一步走多远。上例取 0.1，得到 $w_{new}=1-0.1\times(-4)=1.4$，新的 L 为 2.56，确实比 4 小。

梯度只提供当前位置的变化信息；步子太大可能越过低点并震荡。此处的 L 可以先理解为“希望变小的误差分数”，机器学习一节会具体定义它。

### 基础 A-8｜随机变量、概率与分布

一次掷骰子的结果尚不确定，可以用**随机变量 X**表示。$P(X=6)=1/6$ 是某个结果的概率；$P(X\ge5)=1/3$ 是一个事件的概率。

**概率分布**说明不同结果分别有多大概率。离散变量的各个结果概率相加为 1。连续变量如测量误差，常用**概率密度**描述：区间内概率是密度在该区间的面积，密度本身不是某个精确值的概率，也不必小于 1。

**样本**是实际观察到的结果，例如十次掷骰子；**总体／目标分布**是我们希望了解的结果来源。用有限样本推断分布会有不确定性。

### 基础 A-9｜期望、方差和标准差

**期望**是按概率加权的平均。例如公平骰子的期望为 $(1+2+3+4+5+6)/6=3.5$。它描述平均水平，不要求某次真的出现 3.5。

**方差**衡量结果偏离期望的平方距离：先算与均值的差，平方，再按概率平均。**标准差**是方差的平方根，单位与原变量一致。

X 等概率取 1、3：均值是 2，方差是 $[(1-2)^2+(3-2)^2]/2=1$。Y 总取 2：均值也为 2，方差为 0。平均表现相同，波动可以不同。

计算一组已有数据的平均平方偏差与“用样本估计总体方差”是不同任务；后者常见的无偏样本方差分母用 n-1。先理解方差在量什么，再分清估计公式的条件。

### 基础 A-10｜条件概率、独立与贝叶斯

**条件概率**是在已知某条件成立后重新计算概率。10 个球里有 6 红、4 蓝；红球中 2 个带标记，蓝球中 1 个带标记：

- 随机抽到红球的概率为 6/10。
- 已知是红球，带标记的概率为 2/6，写作 $P(标记\mid红)$。
- 已知带标记，是红球的概率为 2/3，写作 $P(红\mid标记)$。

竖线 $\mid$ 读作“在……条件下”。两个方向的条件概率不同，贝叶斯公式用来转换方向：

$$P(红\mid标记)=\frac{P(标记\mid红)P(红)}{P(标记)}=\frac{(2/6)(6/10)}{3/10}=2/3.$$

**独立**表示得知一个事件，不改变另一个事件的概率。例如两次独立抛硬币；“不同样本”并不自动意味着独立，同一关卡的多个搜索结果共享关卡难度。

### 基础 A-11｜常见分布、似然、MLE 和 MAP

**Bernoulli 分布**描述一次成／败，参数 p 是成功概率；**Binomial 分布**描述 n 次独立同概率尝试中的成功数；**Gaussian／正态分布**是常见的连续分布，由均值和方差控制中心与宽窄。选择分布是在做建模假设，需要看数据是否符合。

假设硬币正面概率为 p，观察十次里八次正面。**似然**把已观察到的数据固定，比较不同 p 对这份数据的解释程度。对给定顺序的结果，其似然是 $p^8(1-p)^2$；若只统计正面数，还多一个与 p 无关的组合系数。

**MLE，最大似然估计**：选让似然最大的参数，这里是 p=0.8。**先验**表示观察这份数据前对参数的分布假设；**后验**是结合数据更新后的分布。**MAP，最大后验估计**：选后验最大的参数，同时考虑似然与先验。

注意：似然是把数据固定后关于参数的函数，不是自动归一化的“参数取值概率”。只有明确参数先验等建模后，才谈对应后验。

### 基础 A-12｜损失、交叉熵与 KL 的第一层直觉

**损失函数 loss**把预测与目标之间的差距变成一个数，便于优化。预测数值可以用平方误差；预测类别概率，可以对真实类别的预测概率 p 使用 $-\log p$：

| 给真实类别的概率 p | 损失 $-\log p$ | 含义 |
|---|---:|---|
| 0.8 | 约 0.223 | 对真实类别分配了较多概率 |
| 0.2 | 约 1.609 | 对真实类别分配了较少概率，惩罚更大 |

这是一类**交叉熵**损失。**熵**描述一个分布自身的不确定性；**KL 散度**比较两个分布的差异，方向交换后通常不同。先区分三个对象，公式与梯度在 A15、A16 再读。

### 基础 A-13｜从有限实验推断结论，为什么需要统计

跑十次成功七次，**样本成功率**为 0.7；它是对目标表现的估计，不证明未来所有任务都恰好 70%。换一组任务或随机种子，结果可能改变。

**大数定律**说明在相应条件下，增加样本能让样本均值趋近真实均值。**中心极限定理**在相应条件下描述均值估计误差的近似分布。**标准误**衡量估计量的波动，不同于单次结果的标准差。

**置信区间**用区间呈现估计的不确定性，要说明统计假设与抽样单位。**bootstrap**通过有放回重采样估计波动；同一关卡重复运行时，可以整组重采样关卡，并保持方法间配对。不是把所有数字放进统计工具，就自然得到可信区间。

### 基础 A-14｜暂时认得含义即可的进阶词

| 术语 | 第一层理解 |
|---|---|
| 秩 | 矩阵中有多少个独立方向；可识别线性重复信息 |
| 特征向量／特征值 | 某些方向经矩阵变换仍沿原方向，只改变倍数 |
| SVD，奇异值分解 | 将矩阵拆成方向变换与沿各方向的缩放；可用于低秩近似 |

| 半正定 | 对称矩阵 A 对任何 x 都满足 $x^\top Ax\ge0$ |
| 凸函数 | 任意两点间线段不低于函数图像；可微凸问题的驻点有全局最小性质 |

## 20 道典型问答

### A01 [P0] 如何分析复杂度？哈希查询一定是 O(1) 吗？

先定义输入规模，再计算主要操作次数与辅助存储。常见哈希表查询／插入平均或期望 O(1)，不保证所有输入下最坏 O(1)；碰撞和实现会影响最坏情况。排序通常 O(n log n)，双重循环也要看各循环实际执行次数。

追问：对 n 个元素做 n 次逐渐增长列表的复制，总代价可能为 O(n²)，不能只看最外层循环。Python 的 `list.pop(0)` 需要移动元素，BFS 队列宜用 `deque`。

### A02 [P0] 二分查找为什么容易错？怎样找第一个大于等于 x 的位置？

用半开区间 `[lo, hi)`，初始化 `lo=0, hi=n`。循环不变量：`lo` 左侧都小于 x，`hi` 及右侧都大于等于 x；检查 `a[mid] < x` 则 `lo=mid+1`，否则 `hi=mid`。终止时 `lo` 是插入位置，可以等于 n。

必须核对空数组、全部小于 x、全部大于等于 x、重复值。对答案二分还要证明判定函数单调，不能仅因答案是数字就二分。

### A03 [P0] 从 n 个数找最大的 k 个，有哪些方法？

全排序 O(n log n)；维护大小为 k 的最小堆 O(n log k)、额外 O(k)；Quickselect 期望 O(n)，某些选枢轴方式最坏 O(n²)。若要求输出有序，选完 k 个还要排序 O(k log k)。流式输入适合堆。

追问：先澄清重复数是否保留、k=0／k>n 如何处理、“第 k 大”是否按不同值计数。

### A04 [P0] BFS 与 DFS 怎样选？为什么 BFS 能求最短路？

BFS 按边数逐层扩展，因此在无权或等权图上首次发现节点时得到最少边数距离；用队列，通常入队时标记访问。DFS 更适合连通性、回溯、拓扑相关过程，不保证首次到达是最短路。邻接表遍历通常 O(V+E)。

有不同非负边权时用 Dijkstra，不能直接套普通 BFS；负权边需要其他算法。图含环时必须考虑访问标记／路径状态，递归 DFS 还要考虑栈深。

### A05 [P1] 动态规划和贪心有什么区别？怎样设计 DP？

DP 要明确状态含义、转移、初始化、计算顺序与答案位置，利用可复用子问题。贪心每步选择局部最优，需要交换论证或其他正确性依据；看起来“自然”不构成证明。

例：最少硬币，`dp[s]=min(dp[s-c]+1)`，只从可达状态转移，`dp[0]=0`。任意币制不能总选最大面额；币值 1、3、4，金额 6 的贪心解是 4+1+1，最优为 3+3。

### A06 [P0] 推导线性回归的矩阵梯度，并标出维度。

令 $X\in\mathbb R^{n\times d}$、$w\in\mathbb R^d$、$y\in\mathbb R^n$，$L=\frac1{2n}\|Xw-y\|_2^2$，则

$$\nabla_w L=\frac1nX^\top(Xw-y),\qquad \nabla_w^2L=\frac1nX^\top X.$$

残差是 n 维，左乘 $X^\top$ 后变成 d 维。加入 $\lambda\|w\|^2/2$ 后梯度加 $\lambda w$。最小二乘闭式解要求相关矩阵可逆；实际数值求解可用分解／伪逆，不必显式求逆。

### A07 [P0] 贝叶斯公式是什么？高准确率检测为什么可能产生很多误报？

$$P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)},\quad P(B)=\sum_iP(B\mid A_i)P(A_i).$$

例：某事件基准率 1%，检测真阳性率 99%、假阳性率 5%，阳性后事件概率为 $0.99\times0.01/(0.99\times0.01+0.05\times0.99)\approx16.7\%$。不能把 $P(B\mid A)$ 当作 $P(A\mid B)$；先验基准率很关键。

### A08 [P0] 期望和方差有哪些常用性质？需要独立吗？

期望线性性不需要独立：$E[aX+bY]=aE[X]+bE[Y]$。方差为 $\operatorname{Var}(X)=E[X^2]-E[X]^2$，且

$$\operatorname{Var}(aX+bY)=a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y).$$

独立且二阶矩存在时协方差为 0。独立同分布、方差 $\sigma^2$ 的 n 个样本，其均值方差为 $\sigma^2/n$；同一任务重复采样存在共享结构时，不能直接当 n 个独立任务。

### A09 [P1] 独立与不相关等价吗？

独立在二阶矩存在时推出不相关，反向一般不成立。取关于 0 对称的非退化 X、令 $Y=X^2$，如 X 均匀分布于 [-1,1]，则协方差为 0，但 Y 由 X 决定，不独立。联合高斯变量在适当条件下，不相关可推出独立。

### A10 [P1] 常见分布对应什么问题？

Bernoulli 表示一次二元结果，均值 p、方差 p(1-p)；Binomial 表示 n 次独立同概率 Bernoulli 的成功数，均值 np、方差 np(1-p)。Categorical 表示一次多类别结果；Gaussian 常用于连续噪声近似；Poisson 表示特定过程中的计数，均值与方差均为 λ。

不要因“是计数”就默认 Poisson，或因“取平均”就声称有限样本严格正态；必须说明建模和近似前提。

### A11 [P0] MLE 与 MAP 有什么区别？正则怎样联系先验？

MLE 最大化 $p(D\mid\theta)$；MAP 最大化 $p(D\mid\theta)p(\theta)$。通常转成对数避免连乘，独立样本的 log likelihood 可相加。

在常见参数化和尺度约定下，高斯参数先验对应 L2 惩罚，Laplace 先验对应 L1 惩罚。MAP 是参数后验的点估计，不等于完整贝叶斯预测；具体正则系数还受噪声方差、样本平均方式影响。

### A12 [P1] 大数定律与中心极限定理分别说什么？

在经典独立同分布且可积条件下，样本均值收敛到总体均值。经典 CLT 在独立同分布、有限非零方差等条件下，描述 $\sqrt n(\bar X-\mu)/\sigma$ 的极限分布为标准正态。

前者讨论一致性，后者给出波动的近似尺度和形状；都不表示任意小样本或重尾／相关数据能直接套正态置信区间。

### A13 [P1] 特征值、SVD、半正定有什么用？

方阵特征分解研究不改变方向的向量；SVD 可用于任意实矩阵 $X=U\Sigma V^\top$，揭示秩与低秩近似。实对称矩阵 A 半正定当且仅当所有特征值非负，也即任意 x 都有 $x^\top Ax\ge0$。

联系：$X^\top X$ 半正定；PCA 与中心化数据 SVD 相关；Hessian 的谱影响优化曲率。不要把秩不足和“完全没有信息”混同。

### A14 [P1] 凸优化与非凸优化有什么区别？梯度为 0 就最优吗？

可微凸函数的一阶驻点是全局最小点；严格凸函数若最小点存在，则唯一。非凸问题的驻点可能是极小、极大或鞍点。Hessian 在局部可辅助判断，但半正定情形本身不总足够作严格分类。

梯度下降步长过大可能震荡或发散；“沿负梯度走”只说明局部方向，不保证任意步长或一般非凸问题达到全局最优。

### A15 [P1] 推导 softmax＋交叉熵梯度，怎样防数值溢出？

对 logits z，$p_i=e^{z_i}/\sum_je^{z_j}$，$L=-\sum_i y_i\log p_i$，标签满足 $\sum_i y_i=1$，则 $\partial L/\partial z_i=p_i-y_i$。推导可从 $L=\log\sum_je^{z_j}-\sum_i y_iz_i$ 开始。

用 $m=\max z$，计算 $\log\sum e^z=m+\log\sum e^{z-m}$。减同一常数不改变 softmax。合法动作／attention mask 若使整行都无有效项，要显式处理，不能期待 `-inf` 运算自动给出合法分布。

### A16 [P1] 熵、交叉熵、KL 有什么关系？

离散分布下，$H(p)=-\sum p\log p$，$H(p,q)=-\sum p\log q$，$D_{KL}(p\|q)=\sum p\log(p/q)$，因此 $H(p,q)=H(p)+D_{KL}(p\|q)$。KL 非负、通常不对称，不是距离；当 p 正而 q 为 0 时可能无穷大。

标签分布固定时，最小化交叉熵等价于最小化该方向的 KL。连续微分熵的性质不同，不能把离散熵“总非负”的直觉直接推广。

### A17 [P1] 成功率的置信区间怎么解释？重复同一关卡怎样统计？

若 n 次独立 Bernoulli，样本成功率 $\hat p$ 的标准误近似 $\sqrt{\hat p(1-\hat p)/n}$；小样本或接近 0／1 时别只用简单正态区间，可考虑 Wilson 或其他合适方法。频率学置信区间描述构造程序的覆盖率，不能直接解释为固定参数落在当前区间内的后验概率。

同一关卡多种子比较时，先确定估计的是关卡泛化还是固定关卡搜索随机性。要估计跨关卡差异，可对关卡作聚类配对 bootstrap，整组保留重复种子；不能用重复次数夸大独立关卡数。

### A18 [P1] 蒙特卡洛估计误差怎样下降？为什么最好一次搜索不是期望价值？

在独立同分布、有限方差条件下，样本均值标准误通常按 $1/\sqrt n$ 下降，想减半约需四倍样本。重复采样相关、分布变化或重尾时，简单结论可能失效。

样本最大值是已发现的最好样本，不是期望回报或最优值证明。若是可信确定性模拟器中的有效可执行路径，可为最优回报提供下界；随机环境里的幸运样本不能直接这样解释。联系 4a：搜索证据完整与排序可靠是不同问题。

### A19 [P1] 如何从长度未知的数据流等概率取一个元素？

蓄水池采样：第 i 个元素到来时，以 1/i 概率替换当前样本。第 j 个元素最终保留概率为 $(1/j)\prod_{i=j+1}^n(1-1/i)=1/n$。一次扫描、O(n) 时间、O(1) 空间。

追问：抽取 k 个用大小 k 的池；随机源、可复现 seed 与真正等概率是不同要求。

### A20 [P1] Dijkstra 与 A* 有什么区别？启发式越大越好吗？

Dijkstra 按当前已知路径代价 g 扩展；A* 按 $f=g+h$ 扩展。非负边权下，Dijkstra 有相应最短路保证。A* 的 h 可采纳性是不高估真实剩余代价；图搜索中一致性、关闭节点与是否允许重开也影响保证。

h=0 时退化为 Dijkstra。过高估计可能更快但失去最优性，不能只以扩展少为好。搜索状态要包含影响后续转移／代价的信息。
