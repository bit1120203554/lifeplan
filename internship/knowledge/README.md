## 基础起步：10/20 起先按概念推进

原来的问答偏向复习，隐含了对术语和符号的理解。现在基础部分先讲“是什么、解决什么、例子怎样算”，再连接公式和面试题。每次选一至两个小节，约 20—30 分钟；没读完就接着读，不用为赶进度跳过不懂的词。

| 起步顺序 | 先读哪些基础小节 | 这一轮只需做到 |
|---|---|---|
| 1，建立学习过程 | A-1；B-1—B-4 | 认识函数、样本、特征、标签、模型、参数和损失，能算一个预测误差 |
| 2，理解参数怎样改 | A-6—A-7；C-1—C-4 | 认识向量／矩阵与 shape，复算一次前向、梯度与更新 |
| 3，理解怎样检查效果 | B-5—B-9 | 解释训练／验证／测试、过拟合、正则和 precision／recall |
| 4，补概率底座 | A-8—A-13 | 区分概率与观察结果，算期望、方差和一个条件概率例子 |
| 5，理解语言模型 | C-8—C-12 | 解释 token、embedding、注意力、mask、生成和 KV cache |
| 6，理解 Agent 系统 | D-1—D-7；D-11 | 走通调用工具与观察回写，说明 RAG 的步骤与评价对象 |
| 7，接回你的研究 | A-4；D-8—D-10、D-12 | 区分搜索、奖励／回报、价值、策略更新与程序修订 |

一行可以用多次学习完成，不规定必须一天读完。C-5—C-7、B-10—B-11 等概念在遇到相应问题时回查；矩阵分解证明、多卡方案和后训练损失放在后续。

每次只留下两项：**用自己的话解释一个概念，手算或走通一个例子**。例如解释“损失怎样量预测误差”，并算出预测 2、目标 5 时平方误差为 9。完成后再尝试对应的一两道题；不会时回到例子，不先背回答段落。

P0 表示复习优先级，不是当前必须已经掌握的门槛。旧的 10/15—28 日程保留为复习阶段参考；现阶段以这个基础顺序为准，不按旧日期补赶任务。

**P0**：首轮优先，达到能口述、解释公式或写出核心过程。**P1**：基础之后补；目标岗位明确要求时升为优先。这个排序是针对你的岗位和现有经历的判断，不是企业统一考试范围。题目是典型训练问题，没有使用未公开公司题库，也没有统计其出现频率。

## 如何练到能面试

基础阶段先读定义、看例子并复算。理解后再按“**结论 → 原理／公式 → 一个例子 → 适用边界**”回答面试题：先尝试回答，再看要点；合上材料复述，隔天换一个例子重答。知识题通常先练 60—90 秒，追问再展开；初学概念时不计这个时限。涉及推导、代码时另给充分时间。

| 自评分 | 可观察的表现 |
|---|---|
| 0 | 无法说明概念或选方法 |
| 1 | 能认出术语，依赖提示，核心推导／实现有误 |
| 2 | 能独立解释、算例或实现，知道主要边界 |
| 3 | 能比较替代方法、处理反例，并联系自己的真实工作 |

P0 先争取 2 分，不要求所有 P1 都到 3 分。编码另检查输入澄清、复杂度、独立实现和边界；不能只根据看懂答案评分。
