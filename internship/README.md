# Internship — 北京研究实习与 2027 校招

更新：2026-10-05。实习／校招资料统一放此目录（实际名称为 internship）。本周入口：[投递与联系](application-plan-2026-10-04.md)。

## 定位
- **核心目的**：取得就业选择，获得前沿研究视野与科研带教，尽量让实习和硕士课题相互帮助。
- **时间点**：现在启动（2026-10-01），不等新方向论文录用；并行保留 2027 届校招。
- **方向**：LLM Agent 算法/研究，偏规划、搜索、程序策略、反馈评估和自进化；相邻应用算法/CV 为备选。
- **约束**：北京；近期可到岗；每周最多 4—5 天；六个月也可以。毕业风险存在，正式到岗负荷需与学校导师落实。

## 你的情况
- ICCV 2025 一作是已有科研经历，但不保证满足所有研究岗的学位/实践要求。
- 无实习经历，简历突出自己实际承担的研究、实现与验证；新项目如实标记为在研。
- 简历包含车队等竞赛经历；限时算法编码能力需要独立准备，不能以团队奖项代替。
- 新方向不是单纯博弈论；搜索/策略更新经历不能直接写成大规模 LLM 强化学习训练经历。
- 接受实习时要核实直接研究 mentor、前四周任务、毕业回校及成果使用条件。

## 实习投递思路
1. 第一轮以明确策略模块、技术评测或 Agent 应用开发任务为入口，先做两次适配沟通／资格核查，争取一个有依据的投递。顶尖项目和后训练主线只作条件尝试，按 10/5 重排执行。
2. 以具体任务、mentor 和出勤决定优先级；核实能否共用研究问题/实验，不能仅依据“大模型”标签。
3. 每家公司毕业窗口和投递次数分别核查。本周实际状态写在 application-plan；大范围调研里的原 tracker 留作候选池，目前均未代为申请。
