# Agent 算法实习：面试准备与科研训练提纲

更新：2026-10-01；4a 项目讲述同步至 2026-10-05。目标：北京 LLM Agent 算法/研究实习，偏规划、搜索、反馈评估、自进化；同时准备少量 2027 校招。默认求职与申博准备合计约八小时/周，科研继续围绕一条主线。

**先达到“能参加面试并得到有效反馈”，再补目标岗短板。无需等学完整套 ML、RL 或刷完 Hot 100 才投。** 已有 ICCV 一作是研究经历，当前的薄弱处需要通过编码、项目解释和训练实践分别定位，不把它们合并成“自己完全不会”。

## 1. 先准备两项真实项目

### ICCV 工作：已经完成的研究能力证明

准备 90 秒版和 5 分钟版，依次讲：

1. 高光谱干涉成像复原的问题及输入/输出，为什么普通重建方法不足。
2. 物理退化模型怎样进入深度展开网络；哪些模块自己设计和实现。
3. 核心实验、基线、消融与失败案例；只使用论文里可核实的数字。
4. 最难的一次问题如何定位、如何排除替代解释、最终学到了什么。
5. 转向 Agent 的原因：想研究语言先验与真实决策反馈，而已有经验在机制设计、实现和实验评估上可以迁移。

面试前重新打开论文和实验记录，整理一张架构图、一张关键结果表和一个具体失败案例。不要只背摘要、会议等级与榜单名次。

### 新方向：展现思考和工程能力，不伪造完成度

以 4a 当前版本为主：

- **问题**：语言策略怎样成为可分别检验的决策分量？怎样从搜索证据形成可复用的局部策略修改？
- **机制**：共享特征图与独立策略头、MoE 引导 MCTS、搜索续程证据审计及局末组合权重更新；用具名特征与执行记录连接证据和程序编辑，再隔离验证候选。
- **现状**：编译、审计与局部进化原型已实现。10/5 首轮在线只接受一次低参与头删除，配对开发表现持平；生成修订未被接受，尚未证明进化收益。旧环境/旧版本成绩不能贴到新版。
- **下一步**：核查有限搜索证据的可靠性，检验特征是否表达有效区别，并在相同预算下比较仅搜索、先验引导、仅调权与局部进化。
- **个人贡献**：根据实际提交与工作说明编译、搜索、调试、评价设计的责任，区分工具生成与自己的设计/验证。

4b/4c 不作为本次简历更新的完成项目。主项目名称使用“SkillMCTS：语言策略的搜索审计与局部程序进化（在研）”；区分原型机制实现、在线接受的修改与尚待证明的性能收益。当前依据和真实案例见[10/5 简历修改记录](resume-update-2026-10-05.md)。

研究成果不可靠时，面试重点是**能清楚说明已知、未知、失败原因与验证方法**。诚实呈现原型比编造漂亮成绩更经得住追问。

| Agent 与评价 | 状态/观测、工具调用、执行循环、记忆、规划、反思、RAG、错误恢复、停止条件；成功率、成本、稳定性 | 画出一条任务从观测到验证的闭环；说明失败在模型、规划、工具还是评价器 |
| 搜索与决策 | MDP/POMDP 基本概念、BFS/A*、MCTS 四阶段、UCT/PUCT、先验/价值、探索利用、预算 | 解释先验有害时怎样纠偏，以及确定性可模拟环境与真实不可回滚操作的差别 |

## 3. 按岗位选择 P1，不全部同时学

### A. Agent 后训练 / RL（百度策略、阿里 Accio、小米、部分美团/小红书/商汤）

需要掌握：

- SFT 的数据格式、监督目标与轨迹来源；LoRA/PEFT 的作用、训练参数和限制。
- 奖励、价值、优势、策略梯度；REINFORCE、baseline、Actor-Critic、on-policy/off-policy。
- PPO 的概率比和裁剪动机；DPO 的偏好对及参考策略；GRPO 的组内相对反馈与适用条件。能读关键损失与解释梯度方向，不只背缩写。
- RLHF 与可验证奖励的区别；奖励噪声、reward hacking、稀疏奖励、长程信用分配、探索不足、分布漂移。
- Agent 的 rollout、工具/环境反馈、训练 token 与 mask、任务成功的归因、失败轨迹如何用于训练。
- 基础训练排错：loss 不下降、梯度异常、奖励不涨、长度变长却效果不变、训练评价不一致。
- 多卡/分布式概念只按 JD 深度补。没有实践就说明尚未做过，不能把读过 DDP/FSDP 当成经验。

你当前的搜索/信任权重更新与深度 RL 有关联，但**不是大规模神经模型 RL 训练经历**。投应用或研究岗可以展示可迁移能力；小米等明确要实训的岗位，应优先补一个有边界的真实训练练习。

原始材料：[PPO](https://arxiv.org/abs/1707.06347)、[DPO](https://arxiv.org/abs/2305.18290)、[DeepSeekMath 中的 GRPO](https://arxiv.org/abs/2402.03300)。框架参考 [TRL DPO](https://huggingface.co/docs/trl/dpo_trainer)、[TRL GRPO](https://huggingface.co/docs/trl/grpo_trainer)。这些基础材料不是 2026 最新算法的完整综述。

**最小实作建议，二选一**：有可用 GPU 时跑一项小模型 SFT/LoRA 练习并分析数据与损失；没有 GPU 时用现有环境/小策略练习采样、奖励、优势和更新，明确这不是完成了 LLM 后训练。一次练习只回答一个技术问题，时间上限约一个工作日；算力不足不为准备面试购买昂贵资源。

### B. 自进化、搜索与程序 Agent（与你当前最直接）

- 程序生成—执行—验证—选择—修订闭环；编译成功率、运行成功率与任务成功率分别统计。
- 对象是程序/提示/外部策略，还是模型权重？两种“自进化”需要不同验证。
- 搜索反馈与最终任务回报之间的偏差；规则未知时，真实交互和模拟条件分别是什么。
- 可验证奖励、Verifier/Judge 可靠性；错误评价如何诱导无效改进。
- best-of-N、树搜索和策略更新怎样在相同成本下比较；重复试验如何影响 pass@k 与 pass@1。
- 记忆与程序库怎样更新，如何防止遗忘、污染、过度特化，怎样测跨任务迁移。

与你项目直接相邻的原始材料：[LATS，ICML 2024](https://proceedings.mlr.press/v235/zhou24r.html)；[AlphaEvolve 初始介绍，2025](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/)及[2026 年应用更新](https://deepmind.google/blog/alphaevolve-impact/)。阅读时比较具体机制、条件与计算预算，不能因为都涉及搜索或进化就视为同一方法。

### C. 应用 Agent / RAG（更容易与现有编码衔接的备选）

- 检索、chunking、embedding、召回/重排；检索质量与最终答案质量分别评价。
- function calling/结构化输出；工具接口、超时、重试、幂等、权限边界、轨迹日志。
- 工作流与自主规划的取舍，多 Agent 的收益是否超过额外成本。
- 幻觉、上下文压缩、记忆检索、错误恢复、离线回归集及业务指标。
- MCP 是工具/上下文连接协议，理解接口与调用过程即可；不是用了框架就完成算法创新。

不要为简历额外做一个庞大聊天产品。优先把现有项目的运行日志、验证器和评价材料整理成能解释的系统。

## 4. 编码从这些题型起步

先用最熟悉的语言，不为面试临时同时学 Python 和 C++。岗位明确要求 C++ 时再增加相关训练。[力扣官方 Hot 100](https://leetcode.cn/studyplan/top-100-liked/)可作题目入口，本计划只取小部分。

| 题型 | 起步代表题（编号） | 要练出的能力 |
|---|---|---|
| 哈希 | 两数之和 1 | 查询与更新顺序，重复值 |
| 双指针 | 移动零 283；三数之和 15（后做） | 原地修改、不变量、去重 |
| 滑动窗口 | 无重复字符的最长子串 3 | 窗口什么时候收缩 |
| 二分 | 二分查找 704 | 边界约定，不混用闭/开区间 |
| 栈 | 有效括号 20 | 配对状态与空栈边界 |
| 链表 | 反转链表 206 | 指针更新和空输入 |
| 树 | 二叉树层序遍历 102 | 队列与层边界 |
| 图/网格 | 岛屿数量 200；课程表 207（后做） | visited、BFS/DFS、拓扑依赖 |
| 堆 | 数组第 K 大元素 215 | top-k、复杂度与选取策略 |
| 回溯 | 全排列 46（后做） | 递归状态、撤销修改 |
| DP | 爬楼梯 70；打家劫舍 198；零钱兑换 322（后做） | 状态、转移、初始化 |

每周约三个 50 分钟编码时段：先练两道新题，另一次复写旧题与纠错。前两周完成 4—6 道基础题并能独立复写；六周累计约 12—16 道掌握的代表题即可作为起步，**不保证覆盖校招笔试或通过率**。遇到难点可以减少题量，优先确保写得出。

单次方法：先读输入输出和例子 → 写朴素解/复杂度 → 找关键状态 → 实现 → 测空输入、重复值、边界 → 口头解释。独立尝试约 20 分钟无进展可读官方思路，当天关闭答案复写，隔两三天再写。准备时可用 AI 指点；面试按考场规则独立完成。

## 5. 三十个核心自测问题

### 项目与研究（1—8）

1. 你的 ICCV 论文到底解决哪个问题，物理模型为何必要？
2. 你本人完成什么，哪项实验最能支持贡献？
3. 一个你做错的实验是什么，怎样定位和修复？
4. 新项目与现有语言规划/搜索方法的区别是什么？哪些区别目前还没验证？
5. 编译成功与任务成功的区别是什么，生成失败怎样统计？
6. 搜索证据能说明什么，不能说明什么？“没有证据”为什么不等于低价值？
7. 为什么需要权重更新？错误/偏置证据会造成什么后果？
8. 怎样比较方法收益与增加计算预算的收益？

### ML/DL/Transformer（9—16）

9. 交叉熵和 KL 怎样联系，为什么使用 log 概率？
10. 训练/开发/测试怎样划分，反复调测试集会怎样？
11. Adam 与 SGD 的主要区别，训练不收敛先排查什么？
12. LayerNorm 与 BatchNorm 的计算维度和适用条件？
13. Q/K/V 的 shape 是什么，为什么注意力要缩放？
14. causal mask 与 padding mask 的作用各是什么？
15. KV cache 缓存什么，增加了什么资源开销？
16. eval、no_grad 与参数冻结为什么不是一回事？

### Agent、搜索与 RL（17—25）

17. 一个工具 Agent 循环怎样组织，怎样终止并恢复工具错误？
18. 工作流、搜索与端到端训练各在什么条件下合适？
19. MCTS 怎样选择/扩展/模拟/回传，UCT 与先验引导有什么区别？
20. 环境不能回滚，或规则未知时，你的搜索怎样改变？
21. RAG 检索失败与生成失败如何区分？
22. REINFORCE 为什么需要 baseline，Actor-Critic 的价值网络干什么？
23. PPO、DPO、GRPO 的训练数据与反馈分别是什么？
24. reward hacking 和稀疏奖励怎样发现，如何改评价而不只是改模型？
25. 怎样判断自进化是真实泛化，还是过拟合验证器/任务库？

### 评价与合作（26—30）

26. 成功率提升但时延和 token 成本翻倍，怎样评价？
27. 多次运行和置信区间怎样报告，小样本结论有什么限制？
28. 仓库/测试集变化后，旧结果能否直接与新结果比较？
29. 为什么选这个团队，你希望得到什么带教，又能承担什么工作？
30. 每周五天、六个月实习与学位论文如何安排，哪些条件仍须学校确认？

每题先做到 60—90 秒解释并举一个自己的例子。遇到未做过的技术可说“目前理解到这里，尚无该规模实践，准备通过这项小实验补齐”，不要装作熟悉。

## 6. 六周安排与首轮面试

| 时段 | 主要目标 | 具体输出 |
|---|---|---|
| 第 1 周 | 开始投递；项目讲述、基础编码 | 一页简历；ICCV 与新项目各 90 秒；两道基础题；明确毕业咨询事项 |

八小时的建议分配：编码 2.5 小时、知识与项目 2 小时、投递/面试安排 2 小时、申博 1.5 小时。模拟和真实面试替换知识或投递时段。精读与你研究直接相关的论文放入已有科研时间，**替换漫无目的阅读，不额外增加一项负担**。实习到岗后应减少求职准备并重排科研任务。

30 分钟模拟可按：项目 5 分钟、代码 15 分钟、目标岗技术 7 分钟、反问 3 分钟。真实面试可能更长，这只是练习结构。没写完题时，记录卡在理解、选方法、实现还是边界；答不出知识时记一个可补的概念，不给自己做整体能力判决。

## 7. 前沿视野与科研能力：用反馈循环训练

**每周只围绕一个当前问题精读一篇原始论文/技术报告**。先保留两个关注轴：① 搜索与可执行程序策略；② Agent 后训练、验证器与评价。暂不全面追踪所有大模型新闻。

每次写半页记录：

1. 作者解决的具体问题和假设是什么？
2. 提出的机制与最强替代方法有什么差别？
3. 哪个实验真正支持结论，计算预算是否公平？
4. 哪项失败或限制与我的研究相关？
5. 下一步能做哪个最小实验，结果会怎样改变我的判断？

将同一页用于导师/mentor 讨论、相关工作整理和面试回答。带教的核心价值是有人指出问题和证据中的盲点，而不是只推荐一堆论文。

当前目标岗涉及的评测入口可关注 [SWE-bench 官方说明](https://www.swebench.com/verified.html)和 [Terminal-Bench 2.0](https://www.tbench.ai/?version=2.0)。前者在同一模型下不同 Agent 系统也可能不同；比较结果先看系统、版本、预算和任务划分，不把榜单数字直接视为模型或方法的纯收益。**不要求你现在跑全量基准或拿测试集调参**。

实习面试时询问：是否有固定研究 mentor？是否会讨论问题定义、审查基线与实验？前四周是否能形成一个可复现基线、一份失败分析和一次对照实验？这些可用于评价你是否得到科研训练；四周产出顶会论文不是合理验收标准。

有关岗位与反问，见[61 家岗位筛选](company-research-2026-10-01.md)；毕业/申博负荷见[毕业与申博方案](../phd-apply/recovery-plan-2026-10.md)。本提纲是按当前岗位要求提出的准备建议，不能保证面试通过，也不是公司原样题库。
